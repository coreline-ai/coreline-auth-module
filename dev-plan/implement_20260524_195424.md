이 문서는 R5 hardening 이후 남은 GA 직전 항목을 순차 개발로 닫고, 현재 Mac 환경에서 코드·테스트로 확인 가능한 잔여 항목을 0으로 만드는 작업 문서다.

## 개발 목적
- R5 이후 남은 Medium/Operational 보안 항목을 release 후보 수준으로 정리한다.
- 관측성, 분산 MFA vault, passkey helper, admin audit filtering을 host application에서 즉시 붙일 수 있는 독립 모듈 형태로 제공한다.
- Coreline Auth 독립성 원칙을 유지하면서 현재 Mac에서 가능한 전체 회귀 테스트를 완료한다.

## 개발 범위
- Argon2 password hasher 파라미터 명시.
- AES-GCM decrypt 실패 메시지 uniform 처리.
- Admin audit API `since`/`until` filter 노출.
- exporter-neutral observability sinks 추가.
- Redis-backed encrypted MFA secret vault 추가.
- WebAuthn/passkey 서버측 검증 helper 추가.
- README와 production roadmap 업데이트.
- 신규/기존 테스트 실행.

## 제외 범위
- 외부 SIEM/Grafana/OTel collector 실제 배포.
- Full WebAuthn attestation trust-store 구현.
- Tenant/organization/billing/workspace 등 SaaS 제품 기능.
- 외부 KMS/HSM 연동.
- 실제 Redis/Postgres 운영 클러스터 생성.

## 최종 결과 요약
- R5 이후 남은 코드/테스트 가능 GA hardening 항목을 모두 닫았다.
- 관측성은 exporter-neutral sink 4종으로 패키지 레벨 gap을 닫고, 실제 SIEM/Grafana/OTel 배포는 host integration 범위로 분리했다.
- Redis MFA vault와 WebAuthn assertion helper를 독립 모듈로 추가해 multi-node/passkey 확장 기반을 마련했다.
- 현재 Mac 환경에서 가능한 targeted/package/root/Postgres/docker/demo/lint/build 검증이 모두 통과했다.
- R5 test gap 중 OIDC `alg=none`/`HS256` 거부와 CSRF edge는 회귀 테스트로 추가 확인했다.

- 코드/테스트로 처리 가능한 이번 범위의 잔여 항목은 없음.
