이 문서는 Coreline Auth 데모/모듈의 인증 제품 표면을 Phase A~D 순서로 보강하되, 현재 로컬 맥 환경에서 테스트 가능한 범위 안에서 구현을 완료하기 위한 작업 문서다.

## 개발 목적
- 일반 사용자가 자신의 계정/보안/세션/활동을 직접 확인·관리할 수 있게 한다.
- 관리자가 사용자 상세, 세션, 비밀번호, 상태, 활동을 한 화면에서 관리할 수 있게 한다.
- MFA/Security Center는 기존 core primitive를 데모/관리 화면에 연결 가능한 수준으로 노출한다.
- 운영화 항목은 외부 인프라 없이 검증 가능한 health/runbook/문서/테스트 중심으로 마무리한다.

## 개발 범위
- `src/coreline_auth/examples/saas_app.py` 데모 웹앱 화면/라우트 보강.
- 필요한 경우 `CorelineAdminService`와 storage protocol에 작은 self/admin helper 추가.
- self-service 계정 설정, 세션 관리, 활동 이력, 비밀번호 변경.
- admin user detail 화면, session revoke, password reset, disable/enable.
- MFA 상태/관리 표면과 운영 체크리스트 문서 보강.
- 회귀 테스트 추가 및 `uv run pytest` 전체 통과.

## 제외 범위
- SaaS tenant/organization/team/billing/marketplace.
- 실제 외부 SMTP queue, SendGrid/SES 연동, Redis 서버 필수 통합, OTel collector 실행.
- WebAuthn 브라우저 ceremony 완전 구현.
- 커스텀 role/permission DB CRUD.
- 대규모 프론트엔드 SPA 전환.

## 공통 진행 규칙
- 각 Phase는 앞선 Phase의 자체 테스트 완료 후에만 시작한다.
- 구현 중 발생한 이슈는 해당 Phase에서 수정하고 기록한다.
- 체크박스 상태를 실제 진행 상태와 맞게 업데이트한다.
- 문서에 없는 범위 확장은 하지 않는다.
- Coreline Auth는 CoreMCP와 독립 모듈이며 CoreMCP import를 추가하지 않는다.
