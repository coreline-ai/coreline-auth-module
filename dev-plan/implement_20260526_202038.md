# implement_20260526_202038.md

작성 일시: `2026-05-26 20:20:38 KST`

이 문서는 Coreline Auth에서 현재 로컬 맥 환경만으로 검증 가능한 상용화 보강 항목을 1~5순위로 고정하고, 외부 인프라가 필요한 작업은 명확히 제외하기 위한 작업 문서다.

## 개발 목적
- 실제 SMTP, Google/Facebook credential, Redis/Postgres 서버 없이도 확인 가능한 운영·관리 표면을 완성한다.
- 관리자 감사 로그, 이메일/outbox, provider readiness, 운영 runbook을 데모 웹앱 안에서 직접 검증 가능하게 한다.
- 이미 구현된 인증 core에는 불필요한 대규모 기능 확장을 넣지 않고, 관측성과 운영 판단 UX를 보강한다.

## 개발 범위
- `/admin/audit` 필터 UI 및 query 지원.
- `/system` provider/readiness 카드 보강.
- `/system/email` 개발용 email outbox와 template preview 추가.
- README/self-test/security checklist 문서 업데이트.
- demo webapp 회귀 테스트 및 전체 pytest.

## 제외 범위
- 실제 외부 SMTP 발송 서버 구성 및 credential 검증.
- Google/Facebook 실제 OAuth credential을 사용하는 외부 E2E.
- Redis 서버 또는 Postgres 서버 필수 실행.
- WebAuthn 브라우저 ceremony 완전 구현.
- Tenant/organization/team/billing 등 SaaS 확장.
