이 문서는 Coreline Auth가 기본적으로 멀티 유저 권한과 social login 기능을 포함하도록 확장한 작업 범위를 기록한다.

## 개발 목적

v0.1 self-test 데모가 single-owner 중심으로 보이는 문제를 해소하고, 기본 상태에서 멀티 유저/RBAC/admin/social login 흐름까지 확인 가능하게 한다.

## 개발 범위

- Multi-user role/permission 강화
- Admin core/API 강화
- SaaS demo admin user-management UI
- Google/Facebook connector 및 dev social login
- 참조 소스 비교 문서 업데이트

## 제외 범위

- Generic OIDC connector
- MFA/passkey
- organization/team/workspace/billing
- provider token vault
- production email sender
