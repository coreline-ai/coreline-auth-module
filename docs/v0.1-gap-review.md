# Coreline Auth v0.1 Gap Review

작성 일시: `2026-05-23`

## 결론

현재 v0.1은 **독립 실행 가능한 인증 core + 실제 웹앱 형태의 자체 테스트**까지 가능하다. CoreMCP optional 적용과 social/OIDC connector는 의도적으로 제외되어 있다.

## 구현/누락 매트릭스

| 영역 | 상태 | 근거 |
|---|---:|---|
| 독립 package | 완료 | `pyproject.toml`, `src/coreline_auth` |
| CoreMCP import 금지 | 완료 | `make test` import guard |
| email/password | 완료 | `CorelineAuthService.login_password` |
| password hashing | 완료 | Argon2 (`argon2-cffi`) |
| magic link | 완료 | token hash 저장 + 1회 consume |
| session | 완료 | opaque token + hash-only DB storage |
| SQLite storage | 완료 | `SQLiteAuthStorage` |
| FastAPI JSON adapter | 완료 | `mount_auth_routes`, `require_permission` |
| 실제 웹앱 self-test | 완료 | `coreline_auth.examples.saas_app` — login/signup/magic-link/protected-page |
| CSRF helper | 완료 | `CsrfProtector` |
| login rate limit | 완료 | `FixedWindowRateLimiter` |
| admin core | 완료 | list users / role update / ban / unban / password set / session revoke |
| Google/Facebook/OIDC | 부분 완료 | Google/Facebook connector + dev social login 구현. OIDC 범용 connector와 provider token vault는 후속 |
| full RBAC | v0.3 | v0.1은 profile 기반 |
| CoreMCP 적용 adapter | 후속 | CoreMCP 기본 auth 보존 위해 별도 dev-plan 필요 |
| production email sender | 후속 | v0.1은 interface + in-memory sender |

## 보안 확인

- raw password 미저장 테스트 있음.
- raw session token 미저장 테스트 있음.
- magic link replay reject 테스트 있음.
- open redirect reject 테스트 있음.
- CoreMCP runtime import guard 있음.

## 다음 단계

1. CoreMCP optional adapter 적용.
2. Generic OIDC connector 추가.
3. production email sender adapter 추가.
4. provider token vault 저장 정책 확정.
